# Who Am I? (Vedanta)

An interactive Python terminal program that walks you through the question "Who am I?" using ideas from Advaita Vedanta.

20 short sections, each followed by a pause. Some sections end with a reflection question.

## Run it

Requires Python 3.

    python who_am_i.py

Press Enter to move to the next section. Press Ctrl+C to exit at any time.

## What I practised

- Storing content as a list of data instead of repeating code
- Loops and user input handling
- Clean exit on Ctrl+C or EOF
- Refactoring a working script into cleaner code

## Note

This is not a scientific proof of Vedanta. It is a philosophical walkthrough of the Upanishadic and Advaita tradition. Other Vedanta schools read these ideas differently.
